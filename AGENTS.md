# AI-Dostar team memory

Before changing this repository:

1. Read `docs/team-memory.md` for durable project decisions and current context.
2. If the Mem0 plugin is available, search its `repo` scope for relevant earlier work. Use `mine` only for personal preferences. Verify recalled facts against the code and this document before acting.
3. Record important architecture decisions, commands that actually worked, integration constraints, and unresolved issues in `docs/team-memory.md` during the task. Keep entries concise and date them.
4. Do not put API keys, tokens, passwords, private user facts, or raw chat transcripts in Git or team memory.

Mem0 is additional cross-session recall. `docs/team-memory.md` is the shared source of truth that travels with this repository. See `docs/memory-setup.md` for plugin setup on each teammate's machine.

The Ruflo tools mentioned in a user's or global instructions should be used when available; do not make their availability a prerequisite for working in this repository.
