# AI-Dostar team memory

Before working in this repository, read `docs/team-memory.md` and inspect the current code. Treat the file as a concise handoff for teammates, and verify its claims against the repository.

After every substantial task, update `docs/team-memory.md` before committing or pushing:

1. Record decisions and constraints that future contributors need.
2. Record changed components, verified run/test commands, and unresolved blockers.
3. Date new notes. Edit or remove stale notes instead of appending contradictions.
4. Keep facts brief and specific. Do not add guesses, API keys, tokens, passwords, personal information, or raw chat transcripts.

Commit and push this file with the related code changes. Teammates receive the same memory through `git pull`; no external memory service or account is required.

The Ruflo tools mentioned in a user's or global instructions should be used when available; do not make their availability a prerequisite for working in this repository.
